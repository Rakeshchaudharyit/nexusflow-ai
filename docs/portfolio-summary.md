# Portfolio summary

**NexusFlow AI** is a multi-tenant agent orchestration control plane with MCP tools, supervisor-led teams, durable workers, human approvals, scoped memory, cited retrieval, traces and deterministic evaluation.

Built with Next.js/TypeScript, FastAPI/Python, PostgreSQL/pgvector, Redis/Dramatiq and Docker. The synthetic Acme demo exercises the existing API and worker instead of inserting fabricated completed runs. Production safeguards validate secrets, HTTPS origins, hosts, cookies and private-service configuration.

Text generation and business actions are deterministic simulations. No live provider benchmark or production deployment is claimed. See [validation](m11-validation.md), [demo guide](demo-environment.md) and [deployment](deployment.md) for evidence and limits.
