# NexusFlow AI v1.0.0 — release draft

Unreleased proposal. Current version is 0.1.0; no tag or release has been created. Owner approval, license selection, Git-history audit and clean-clone verification remain required.

## Highlights

An inspectable multi-tenant control plane for agent teams, tools and human-governed execution.

## Core platform

Next.js/TypeScript UI, FastAPI, PostgreSQL/pgvector and authenticated workspace roles.

## AI orchestration

LangGraph specialist teams, MCP discovery and tool grants, durable Dramatiq jobs with retries and cancellation.

## Safety and controls

Policy gates, approval/rejection, tenant boundaries, redacted summaries and production configuration validation.

## Knowledge and memory

Scoped memory, document ingestion, hybrid retrieval and citations.

## Observability and evaluation

Span waterfalls, deterministic regression cases, baseline comparisons and configuration snapshots.

## Deployment

Docker Compose, persistent volumes, migration and single-VPS TLS/backup/rollback documentation. No public deployment has occurred.

## Known limitations

Text generation, email and CRM actions are deterministic simulations. Offline embeddings do not demonstrate production semantic quality. No OCR, node-level checkpoint recovery, token/cost accounting, automatic trace retention or zero-downtime deployment. Production restore drill remains an operator gate.

See [dated validation evidence](../m11-validation.md).
